# Projetos — Edição 2026.2

Este diretório reúne os projetos desenvolvidos pelos grupos na edição 2026.2 da EX071.

> [!WARNING]
> Este arquivo `README.md` faz parte da estrutura do repositório da disciplina e **não deve ser alterado pelos grupos**.
>
> Cada grupo deverá modificar **exclusivamente o conteúdo de sua própria pasta de projeto**.

## Organização

Cada grupo deverá criar uma única pasta dentro deste diretório:

`projects/<nome-do-projeto>/`

O nome da pasta deve funcionar como um **identificador curto e permanente do projeto**. Ele não precisa reproduzir o título completo da atividade.

Prefira nomes:

- curtos e mnemônicos;
- escritos em letras minúsculas;
- sem espaços, acentos ou caracteres especiais;
- com palavras separadas por hífen (`-`);
- suficientemente descritivos para distinguir o projeto dos demais.

### Exemplos

Um projeto cujo título seja:

**“Navegando com Segurança: uma oficina sobre golpes digitais para pessoas idosas”**

poderia utilizar simplesmente:

`golpes-60mais/`

Outro projeto intitulado:

**“IA sem Mistério: entendendo como algoritmos generativos produzem imagens”**

poderia utilizar:

`ia-imagens/`

Evite nomes excessivamente longos, como:

`navegando-com-seguranca-oficina-sobre-golpes-digitais-para-pessoas-idosas/`

O título completo, a descrição e as demais informações do projeto deverão constar no `README.md` **dentro da pasta do próprio projeto**, e não no nome do diretório.
